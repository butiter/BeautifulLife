- 你要写一个脚本，输入api_key，然后自动运行游戏。

- 修改代码，删掉debug的api设置，新增一个setting界面；该界面可以指定api、选择模型。

- 其中，需要为图像生成、低质量文本生成、高质量文本生成指定不同的模型。而后，在原有的代码中，检测用低质量文本生成，生成世界等用高质量文本生成。前面的中括号是提供方，也就是api方。
- 点击填写api，跳出一个对话框，（四个填写api的地方）

    - 豆包（文字或图片）

- 然后，指定提供方（文字和图片各一个提供方，下拉框选）。
- 再然后，在提供方右侧下拉框选选择对应提供方的模型

```DEEPSEEK-文字
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ.get('DEEPSEEK_API_KEY'),
    base_url="https://api.deepseek.com")

response = client.chat.completions.create(
    model="deepseek-chat",
    messages=[
        {"role": "system", "content": "You are a helpful assistant"},
        {"role": "user", "content": "Hello"},
    ],
    stream=False
)

print(response.choices[0].message.content)
```

```OPENAI-图片-响应模式
from openai import OpenAI
import base64

client = OpenAI() 

response = client.responses.create(
    model="gpt-5",
    input="Generate an image of gray tabby cat hugging an otter with an orange scarf",
    tools=[{"type": "image_generation"}],
)

# Save the image to a file
image_data = [
    output.result
    for output in response.output
    if output.type == "image_generation_call"
]
    
if image_data:
    image_base64 = image_data[0]
    with open("otter.png", "wb") as f:
        f.write(base64.b64decode(image_base64))
```

```OPENAI-图片-直接生成
from openai import OpenAI
import base64
client = OpenAI()

prompt = """
A children's book drawing of a veterinarian using a stethoscope to 
listen to the heartbeat of a baby otter.
"""

result = client.images.generate(
    model="gpt-image-1",
    prompt=prompt
)

image_base64 = result.data[0].b64_json
image_bytes = base64.b64decode(image_base64)

# Save the image to a file
with open("otter.png", "wb") as f:
    f.write(image_bytes)
```
